# Nossa Escola, Nosso Cuidado 🏫✨

Um jogo educativo e interativo projetado para ensinar estudantes sobre a importância da cidadania, do cuidado com o patrimônio público e da manutenção do ambiente escolar.

## 🌟 Sobre o Projeto

"Nossa Escola, Nosso Cuidado" transforma o aprendizado sobre conservação escolar em uma experiência gamificada. Os jogadores assumem o papel de cuidadores da escola, resolvendo desafios e realizando melhorias reais no ambiente virtual.

## 🚀 Funcionalidades

- **Quiz Educativo**: Teste seus conhecimentos sobre como manter a escola limpa e organizada.
- **Sistema de Pontos (Pontos de Cuidado)**: Ganhe pontos respondendo corretamente aos desafios.
- **Loja de Melhorias**: Use seus pontos para comprar reformas para a sala de aula, novos equipamentos, plantas e muito mais.
- **Ranking Global**: Compita com outros estudantes para ver quem é o maior cuidador da escola.
- **Autenticação Flexível**: Entre com sua conta Google ou jogue como convidado (Login Anônimo).
- **Progressão Visual**: Veja a sala de aula se transformar de um estado descuidado para um ambiente vibrante e renovado.

## 🛠️ Tecnologias Utilizadas

- **React + Vite**: Frontend rápido e reativo.
- **Firebase**:
  - **Authentication**: Para gerenciar perfis de jogadores.
  - **Firestore**: Banco de dados em tempo real para o ranking e progresso.
  - **Hosting**: Hospedagem segura e rápida.
- **Tailwind CSS**: Estilização moderna e responsiva com design "Neobrutalista".
- **Framer Motion**: Animações fluidas para uma melhor experiência de usuário.
- **Lucide React**: Biblioteca de ícones elegantes.

## 📖 Como Jogar

1. Faça login ou entre como convidado.
2. Responda às perguntas do quiz para acumular "Pontos de Cuidado".
3. **Cuidado!** Se errar uma pergunta, seus pontos serão zerados, incentivando a atenção e o aprendizado real.
4. Acesse a loja e clique nos itens para ver o custo e realizar a melhoria.
5. Complete a "Reforma Geral" para finalizar a renovação da sala e ganhar um selo especial no ranking!

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
